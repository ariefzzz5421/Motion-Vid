# Implementation plan

1. **Foundation:** inspect the existing repository and MIT license, check current official Remotion docs, install the official Remotion Agent Skills, set up Next.js, the design system, schema, and IndexedDB.
2. **Editor:** build the homepage/dashboard, create four data-driven templates, wire the Player to the inspector and timeline, and add edit history plus autosave.
3. **Rendering:** use the same composition for browser MP4 rendering, detect support, show progress/cancellation/errors, and provide a local Node CLI path.
4. **Quality:** test project flows, export/playback, responsive layouts, type checking, lint, and production build; document Vercel deployment and Remotion licensing.
5. **Later:** AI Director, cloud queue, audio, and advanced timeline tools are outside the functional MVP.
